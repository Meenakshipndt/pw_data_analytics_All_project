#### 2. Explain the purpose of constraints and how they help maintain data integrity in a database. Provide examples.

Constraints are rules applied to columns in a database table to restrict the type of data that can be stored in them. They help enforce data integrity, accuracy, and consistency in the database.

🎯 Purpose of Constraints
Ensure valid data entry
Prevent duplicate or missing values
Maintain relationships between tables
Enforce business rules at the database level

🧱 Types of Constraints
1. NOT NULL
Ensures that a column must always have a value. It prevents the insertion of null (empty) values.
2. UNIQUE
Guarantees that all values in a column are different. It helps avoid duplicates.
3. PRIMARY KEY
Uniquely identifies each record in a table. It is a combination of NOT NULL and UNIQUE.
4. CHECK
Validates the values in a column based on a condition. It ensures that data meets specified criteria.
5. DEFAULT
Sets a default value for a column when no value is provided during insert operations.
6. FOREIGN KEY
Creates a link between two tables. It ensures that a column’s value exists in another table, maintaining referential integrity.

#### 3. Why apply NOT NULL to a column? Can a PRIMARY KEY contain NULL? Justify.

The NOT NULL constraint is used to ensure that a column must always have a value.
It prevents missing or undefined values in critical fields.
Applying NOT NULL ensures data completeness and avoids logic errors that may occur when data is absent.
A PRIMARY KEY is meant to uniquely identify each row in a table.
By definition, uniqueness and non-nullability are essential properties of a primary key.
Allowing NULL in a primary key would break its ability to uniquely identify a record, because NULL represents an unknown or missing value, which cannot be compared or relied upon for uniqueness.

### Windows Function:

#### 1. Rank the customers based on the total amount they've spent on rentals.


```python
SELECT 
  customer_id, 
  SUM(amount) AS total_spent,
  RANK() OVER (ORDER BY SUM(amount) DESC) AS rank

```

#### 2.Calculate the cumulative revenue generated by each film over time.


```python
SELECT 
  f.film_id,
  f.title,
  r.rental_date,
  SUM(p.amount) OVER (PARTITION BY f.film_id ORDER BY r.rental_date) AS cumulative_revenue
FROM payment p
JOIN rental r ON p.rental_id = r.rental_id
JOIN inventory i ON r.inventory_id = i.inventory_id
JOIN film f ON i.film_id = f.film_id;

```

#### 4. Identify the top 3 films in each category based on their rental counts.


```python
SELECT category_name, title, rental_count, 
       RANK() OVER (PARTITION BY category_name ORDER BY rental_count DESC) AS rank_in_category
FROM (
  SELECT c.name AS category_name, f.title, COUNT(r.rental_id) AS rental_count
  FROM category c
  JOIN film_category fc ON c.category_id = fc.category_id
  JOIN film f ON fc.film_id = f.film_id
  JOIN inventory i ON f.film_id = i.film_id
  JOIN rental r ON i.inventory_id = r.inventory_id
  GROUP BY c.name, f.title
) sub
WHERE RANK() OVER (PARTITION BY category_name ORDER BY rental_count DESC) <= 3;

```

#### 7.  Identify the customers whose total spending on rentals falls within the top 20% of all customers.


```python
WITH ranked_customers AS (
  SELECT customer_id, SUM(amount) AS total_spent,
         NTILE(5) OVER (ORDER BY SUM(amount) DESC) AS percentile
  FROM payment
  GROUP BY customer_id
)
SELECT customer_id, total_spent
FROM ranked_customers
WHERE percentile = 1;

```

#### 9.  Find the films that have been rented less than the average rental count for their respective categories.


```python
WITH film_rentals AS (
  SELECT c.name AS category_name, f.title, COUNT(r.rental_id) AS rental_count
  FROM category c
  JOIN film_category fc ON c.category_id = fc.category_id
  JOIN film f ON fc.film_id = f.film_id
  JOIN inventory i ON f.film_id = i.film_id
  JOIN rental r ON i.inventory_id = r.inventory_id
  GROUP BY c.name, f.title
)
SELECT * FROM (
  SELECT *, AVG(rental_count) OVER (PARTITION BY category_name) AS avg_rental
  FROM film_rentals
) sub
WHERE rental_count < avg_rental;

```

#### 10.  Identify the top 5 months with the highest revenue and display the revenue generated in each month.


```python
SELECT month, monthly_revenue
FROM (
  SELECT DATE_TRUNC('month', payment_date) AS month, SUM(amount) AS monthly_revenue,
         RANK() OVER (ORDER BY SUM(amount) DESC) AS month_rank
  FROM payment
  GROUP BY month
) sub
WHERE month_rank <= 5;

```
